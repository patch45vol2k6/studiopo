How it works

Three steps from first idea to a script you can hand in.

  1. 1. Start a script

    Pick a template for a short film, stage play or class scene. The format is set up for you.

  2. 2. Write in the flow

    Press Tab to move between scene headings, action, character names and dialogue. The layout follows the standard format.

  3. 3. Share and export

    Send a link to your group or teacher to read or comment. Export a PDF when it's time to submit.
